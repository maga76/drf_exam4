# Smart School — Фронтенд веб-приложения на React JS

Полноценный современный SaaS-интерфейс системы управления школой уровня Linear, Notion и Vercel Dashboard.

## 🚀 Запуск проекта

```bash
cd frontend
npm install
npm run dev
```

Приложение доступно по адресу: `http://localhost:3000`

Для сборки продакшн-бандла:
```bash
npm run build
```

## 👥 Роли пользователей

В верхней панели (`Topbar`) доступен быстрый интерактивный переключатель ролей (Демо):
1. **Супер-администратор** (`super_admin`): управление сетью школ, лицензиями и системными ролями.
2. **Администратор школы** (`admin`): управление учебным процессом, кабинетами, звонками и учителями.
3. **Завуч** (`curriculum_director`): расписание, замены преподавателей, мониторинг живых уроков.
4. **Учитель** (`teacher`): расписание дня, журнал оценок, посещаемость, выдача и проверка ДЗ.
5. **Классный руководитель** (`homeroom_teacher`): профиль класса, ведомости успеваемости, контакты родителей.
6. **Ученик** (`student`): личный электронный дневник, текущий урок, домашние задания, оценки.
7. **Родитель** (`parent`): переключатель между детьми, успеваемость, замечания учителей, уведомления о заменах.

## 📱 Реализованные экраны и модули (27 экранов)

1. **Авторизация (`AuthView.jsx`):** логин/пароль, показ/скрытие пароля, запомнить меня, выбор школы для мульти-школьных аккаунтов, восстановление пароля, быстрый вход по ролям.
2. **Главная панель администратора (`AdminDashboardView.jsx`):** сводка, карточки KPI, живой мониторинг уроков, свободные учителя и кабинеты, предстоящие замены, виджет посещаемости, быстрые действия.
3. **Главная панель учителя (`TeacherDashboardView.jsx`):** график уроков на сегодня, спотлайт текущего урока с таймером, напоминания о заполнении посещаемости, ДЗ на проверке.
4. **Главная панель ученика (`StudentDashboardView.jsx`):** следующий урок, расписание, ближайшие дедлайны ДЗ, последние оценки, GPA (средний балл), посещаемость.
5. **Главная панель родителя (`ParentDashboardView.jsx`):** переключатель между детьми (Алишер 7А, Мадина 4Б), дневник, комментарии педагогов, журнал пропусков, предупреждения о заменах.
6. **Расписание (`ScheduleView.jsx`):** интерактивная недельная сетка (Пн–Сб, 6 уроков), цветные карточки предметов, переключение видов (по классу, учителю, кабинету), фильтры, предупреждения о коллизиях, модалка редактирования, мобильный вид по дням.
7. **Генератор расписания (`ScheduleWizardView.jsx`):** 7-шаговый визард (год/смена, классы, часы, доступность педагогов, кабинеты, верификация, генерация), анимация расчёта, список коллизий с возможностью авто-исправления.
8. **Живые уроки (`LiveLessonsView.jsx`):** монитор уроков в реальном времени, статусы «Идёт», «Скоро закончится», «Замена», «Отменён», фильтры по этажам и корпусам.
9. **Замены (`SubstitutionsView.jsx`):** вкладки «Все», «Ожидают», «Подтверждены», «Отменены», визард оформления замены со свободными учителями и кабинетами, подтверждение и отмена.
10. **Учителя (`TeachersView.jsx`):** реестр преподавателей, статусы (Свободен, На уроке, Отсутствует, Болеет, В отпуске), прогресс-бар нагрузки (фактические/максимальные часы), профиль учителя с доступностью по дням.
11. **Ученики (`StudentsView.jsx`):** личные дела, успеваемость, контакты родителей, массовый импорт CSV/Excel, перевод в другой класс, архивация личного дела.
12. **Родители (`ParentsView.jsx`):** карточки родителей с привязанными детьми (chips), телефоны, email, добавление и редактирование.
13. **Классы (`ClassesView.jsx`):** переключение вида (карточки / таблица), классные руководители, кабинеты, средний балл, детальный профиль класса со списком учащихся.
14. **Посещаемость (`AttendanceView.jsx`):** электронный журнал урока с быстрыми кнопками [П] Присутствует, [Н] Отсутствует, [О] Опоздал, [У] Уважительная, массовая отметка, комментарии, вкладка аналитики пропусков и группы риска.
15. **Оценки (`GradesView.jsx`):** электронный журнал-таблица со столбцами дат и тем, типами оценок (обычная, контрольная, сам. раб.), кликабельный поповер выставления оценок с комментариями, авто-расчёт среднего балла.
16. **Домашние задания (`HomeworkView.jsx`):** сетка заданий, бейджи «Новое», «Срок скоро», «Просрочено», прикрепление файлов, дедлайны, модалка создания и просмотра.
17. **Кабинеты (`ClassroomsView.jsx`):** типы аудиторий (компьютерные, физика, химия, спортзал), статус занятости прямо сейчас, инструмент «Найти свободный кабинет».
18. **Предметы (`SubjectsView.jsx`):** каталог дисциплин, коды, недельные часы, требования к специализированным кабинетам.
19. **Учебные годы и смены (`AcademicYearsView.jsx`):** список годов (активный/архивные), визуальный редактор звонков 1-й и 2-й смены (время начала и окончания уроков).
20. **Объявления (`AnnouncementsView.jsx`):** новостная лента, закреплённые сообщения, фильтр целевой аудитории (учителя, родители, учащиеся), создание и просмотр.
21. **Уведомления (`NotificationsView.jsx`):** центр уведомлений с типами (замены, расписание, оценки, ДЗ), фильтрами, кнопкой «Отметить все» и модалкой каналов оповещений.
22. **Пользователи и роли (`UsersView.jsx`):** реестр пользователей, статусы (активен/заблокирован), сброс паролей, модальное окно матрицы прав доступа по ролям.
23. **Управление школами (`SchoolsManagementView.jsx`):** супер-администраторский мульти-тенант интерфейс, статусы Active/Trial/Blocked, подключение и блокировка школ.
24. **Настройки школы (`SchoolSettingsView.jsx`):** контакты, часовой пояс, 5/10/100-балльная шкала оценивания, резервное копирование и экспорт базы в JSON.
25. **Профиль пользователя (`UserProfileView.jsx`):** персональные данные, смена пароля, язык (RU/TJ/EN), переключатель светлой/тёмной темы, выход.
26. **Отчёты и аналитика (`ReportsView.jsx`):** SVG графики динамики посещаемости по дням, диаграмма качества знаний, сравнение нагрузки педагогов, экспорт в Excel/PDF.
27. **Ошибки и системные состояния (`ErrorStatesView.jsx`):** витрина экранов 403 (Доступ запрещён), 404 (Не найдено), 500 (Ошибка сервера), Skeleton UI, Empty State и валидация форм.
